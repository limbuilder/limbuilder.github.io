About LimBuilder

LimBuilder is an independent developer project focused on building practical web tools, AI utilities, browser games and lightweight online products. The goal is simple: ship small, useful applications that solve real problems without unnecessary complexity.

The portfolio spans media tools, developer utilities, playable browser games, and game guide / wiki sites. Some tools live on this GitHub Pages site; others are standalone products with their own domains.

This homepage is the central directory for LimBuilder experiments — active and offline. New tools will be listed here as they launch.
