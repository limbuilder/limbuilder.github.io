# LimBuilder Homepage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the root redirect with a single-file Ink & Teal personal link hub for LimBuilder that lists yt-converter.

**Architecture:** One static `index.html` served by GitHub Pages. All CSS variables, layout, and keyframe animations live inline. Avatar and favicon come from GitHub’s avatar CDN. No build step, no JS framework.

**Tech Stack:** HTML5, CSS3 (custom properties + keyframes), Google Fonts (Syne + DM Sans), GitHub Pages

**Spec:** `docs/superpowers/specs/2026-07-22-homepage-design.md`

### Task 2: Local visual verification

**Files:**
- Verify: `index.html` (no edits expected unless a bug is found)

- [ ] **Step 1: Serve the site locally**

Run from the repo root:

```bash
python3 -m http.server 8765
```

Leave it running. Open: `http://127.0.0.1:8765/`

- [ ] **Step 2: Check the acceptance criteria in the browser**

Verify all of the following:

1. Page does **not** auto-redirect to `/yt-converter/`
2. Circular GitHub avatar loads
3. Heading shows `LimBuilder`
4. Subtitle shows `tools & experiments`
5. One link row: `yt-converter` / `Free YouTube → MP3 / MP4`
6. Clicking the row opens `/yt-converter/` in a new tab
7. Hover/focus brightens the border toward teal and moves the arrow
8. Entrance stagger and light avatar breath animation play (unless OS reduced-motion is on)
9. Narrow the window (~375px): layout stays centered and readable

Stop the `python3 -m http.server 8765` process (Ctrl+C in that terminal).
